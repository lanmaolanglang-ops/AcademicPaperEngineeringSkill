# AcademicPaperEngineeringSkill v2.7.0

正式稳定版本，基于已验收的 2.7.0-candidate-fix2。调用及安装名称继续使用 `academic-paper-engineering-v2-5`。

## 新增能力与关键修复（相对 v2.5.1）

- 可复现检索：保存查询、时间、数据库、分页与原始响应身份；记录去重、筛选、排除原因与缺失全文，显式保留不完整检索范围。
- 文献可信度：来源身份、发表通知、版本关系、已读范围与主张支持分别核验；绑定通知目标、获取来源、文件 SHA 和上下文，拒绝旧复核错配。
- 方法审查：核方法说明、输入、单位、量纲与有限复算；区分未报告、材料不足和真实错误，不由缺报告推断造假。
- 跨格式定位：Markdown/TXT、PDF、DOCX、XLSX及图像区域；定位成功不授予科学 Verified，扫描材料不声称自动 OCR。
- 三层审计报告：摘要、详细结果和原始证据入口；五态与首次失败保留。中文排版助手保护未映射文本框，拒绝不支持的复杂对象。
- 文件读取受显式 allowed-root 和已打开文件身份约束；输出保留旧文件，不覆盖原稿。

## 本轮整理与许可

只更新版本、许可范围、安装和发行文档及清单；采集器的版本字段和 User-Agent 同步为 2.7.0。核心流程不重构。项目所有者已明确选择 MIT，结合 38 文件来源审计关闭许可范围缺口；原 LICENSE 及版权声明不变。MIT 只覆盖有权许可的项目内容，第三方依赖、用户论文及私人审计资料另行处理。PDF 依赖的 AGPL／商业许可见 [第三方说明](THIRD_PARTY_NOTICES.md)。

## 验证与已知限制

本轮实际回归、隔离安装及 CLI 调用范围见 [VALIDATION](docs/VALIDATION.md)；候选期的真实论文 PDF 有限验收和独立语义复核仅列为历史证据。历史 FAIL、BLOCKED、NOT RUN 均保留。

自动 OCR、真实实验原始数据重算、跨平台／跨文件系统、跨模型认证、真实完整论文最终 Gate、Word 全页 GUI 和实体打印本轮 NOT RUN。复杂 DOCX 对象及 XLSX 公式重算不在现有助手能力保证内。没有重新全面核查真实论文发表通知，不保证不存在撤稿或更正。行为回归 PASS 不等于用户论文 PASS，也不保证真实性、学术合规、原创性、成绩或录用。
