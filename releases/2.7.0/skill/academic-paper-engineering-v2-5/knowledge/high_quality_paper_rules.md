# 高质量论文规则

本表是判断工具，具体结构和证据阈值以文种与任务为准。

| 规则 | 可观察标准 | 不足时的动作 |
| --- | --- | --- |
| 研究问题聚焦 | 对象、分析单位、核心问题及边界可明确表述 | 收窄范围，重写问题 |
| 题目承诺与方法匹配 | “验证”“优化”“机制”等词有真实方法和结果对应 | 降低承诺或补实际研究 |
| 中心论点可检验 | 支持条件、反例和证据缺口可列出 | 保留工作假说身份 |
| 章节形成闭环 | 每章有职责、前提、证据及后续用途 | 合并、移动、补证或删枝节 |
| 段落推进分析 | 主张有证据解释、条件、比较或机制 | 删空泛文字，补有据分析 |
| 技术有工程边界 | 部件到系统链条和适用工况明确 | 查定义、模型与物理边界 |
| 数字含义可追溯 | 每次位置的对象、时期、单位、分母和性质一致 | 重核口径并联动 |
| 来源支持实际观点 | 证据位置与原句直接对应，阅读范围真实 | 换源、拆句或收窄 |
| 计算不掩盖输入缺口 | 公式、算术、参数及外推分别有结果 | 设显式情景或补原始依据 |
| 精度服从证据 | 测量精度、输入有效位与取整可解释 | 降精度并报告不确定性 |
| 图表承担论证职责 | 删除会损失关系、比较或证据 | 省略装饰图或重设作用 |
| 实际字数及版式被核对 | 计数口径和最终页面检查范围有记录 | 压重复、更新域、重导出 |
| 修改可追溯 | 基线、决定、实际写入、复核及恢复链存在 | 建立版本链，查未完成项 |
| 最终验收真实 | Passed有对象、版本、方法与证据 | 缺项标Not Run，不能泛称通过 |

工程分析围绕功能与可行条件；实验报告依据真实观测和误差；综述依据文献比较与分歧；调研报告依据样本、方法和外推边界；科研初稿区分假说与结果。不能把单个案例的固定章节、篇幅、图数或文献数设为所有文种标准。

自然语言优化保护事实、术语、参数和限制。所谓“AI 痕迹”在本 Skill 中仅指模板化、重复和缺乏具体分析的文本质量问题，不是作者身份判定；不预测检测率、成绩和录用结果。
