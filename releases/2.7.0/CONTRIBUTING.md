# 贡献指南

先说明具体用户请求、实际输入范围、发生行为、预期行为、影响和可复核证据；示例必须去敏，不能提交真实论文原件、姓名、学号、私人路径、凭据或历史聊天全文。

修改保持工程克制：优先修当前规则的歧义，不增加无用途Agent、模块、数据库或评分器。保留主张/位置/来源/证据/关系层级及ISSUE/DEC/REV。每个修复说明触发证据和影响文件；规则变更与用户任务授权分开。

测试真实行为，不只搜索关键词。覆盖正向支持、反驳、背景、缺源、重复位置、输入/算术/结论、正式Gate及原稿保护。保存实际输入/响应/产物、方法和限制；未运行就是NOT RUN，失败不删，不能改判据求通过。

新文档用相对链接；安装说明与当前发行物一致。Skill包静态校验、行为测试、宿主发现和论文最终验收分别报告。不得声明未测试模型/平台均兼容。

提交PR前说明许可与来源；不要复制外部代码/Prompt/文档。本项目有权许可的内容按[MIT](LICENSE)提供，范围见[许可状态](LICENSE_STATUS.md)。提交贡献时说明来源，并确认你有权按MIT提供该贡献；本指南不代替其他贡献者的实际授权。第三方内容须单独标明适用许可，不因提交PR自动重新许可；本项目未启用额外CLA。提出贡献建议不等于已批准合并、发布或修改系统配置。
