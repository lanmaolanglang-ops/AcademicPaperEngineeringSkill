# 常见问题与故障排查

| 现象 | 先检查 | 应如何继续 |
| --- | --- | --- |
| 技能列表没有显示 | 当前项目、.agents/skills层级、完整目录、name与文件名 | 按安装指南检查；必要时按实际路径手动加载，明确不算自动发现测试 |
| Agent读到了旧版 | 实际入口路径、metadata.version、同名目录 | 在独立试用项目指定候选路径，不覆盖全局旧版 |
| 说已读但只看到摘要 | 阅读范围、原始文件可读性、截断/OCR | 要求标明全文/片段/元数据；缺失不能补成事实 |
| 直接给出全文与陌生文献 | 是否真的提供来源和正文任务范围 | 回到需求与证据计划，要求具体来源/已读片段，拒绝虚构条目 |
| 台账每条都Verified | 是否混用了汇总、书目真实和单边支持 | 要求逐关系目标/方向/范围及实际位置，不能批量降级代替检查 |
| 找不到同一主张的其它位置 | 是否只记录一个P号 | 检查摘要/正文/表格/图注/结论与同段序号，保留旧新映射 |
| 引用编号正确但观点仍无据 | 是否只做机械编号 | 分开检查Citation Closure与具体证据支持 |
| Word/PDF不存在 | 工具实际调用、返回码、输出路径、文件可读性 | 保留真实失败；交阶段稿和BLOCKED，不造文件或声称生成 |
| PDF可读但页面没查 | 是否只有提取文本或导出日志 | 实际查看页面并记录范围；工具缺失保持NOT RUN |
| 全文流畅却BLOCKED | 最终报告的REQ/SG/ISSUE和关闭标准 | 补对应硬条件，不为得到PASS取消要求 |
| 已改稿但旧报告仍PASS | REV、文件身份与影响范围 | 按变更传播重查，不仅修改报告版本标签 |
| 文档越生成越多 | 是否每个小动作都拆文件 | 合并到一个报告，运行索引仅引用明细，保留必要证据即可 |

工具失败只支持该次失败，不证明所有平台均不可用。重试应有限且目标明确，保留原失败和完成点；不通过安装、提权或改全局安全设置自动绕过限制。求助时提供Skill版本、任务目标、去敏后的错误、实际输入范围和输出身份，不提供密钥或不相关私人材料。
