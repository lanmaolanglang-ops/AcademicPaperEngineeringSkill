# Academic Paper Engineering Skill 2.5.1

这是面向技术论文、课程论文与工程报告的稳定版本分发包。核心仍是论文工程化、证据审计与当前正式对象的独立验收。稳定版本不代表所有论文或全部宿主已通过，实际公开状态以对应 GitHub Release 为准。

## 这次解决什么

- 证据关系八维逐格给出实际依据，保留每份材料自己的 REV；来源必须定位到真实数值行，未读来源不能按题名猜支持上限。
- 重要性未知仍保留完整字段与缺口；算术、参数及结论分验，真实汉字数与总字符数分开。
- 无模板中文稿明确宋体正文、黑体标题、字号、缩进、行距及主题检查；用户模板优先，缺字体不得默默代换后称合规。
- 最终控制器核对当前问题与 16 项 SG 的依赖关系；正向 PASS、缺页检 BLOCKED、未关闭低风险 PARTIAL 三个分支均已实际运行。
- 保持原九模块、六角色、七模板、三知识库与案例路径，不引入新 Agent、后台或自动评分。

## 实际验证与限制

具名证据契约、原生项目发现/普通调用、真实 DOCX/PDF 默认/模板排版及最终 Gate 三分支结果见[验证摘要](docs/VALIDATION.md)。保留首轮 PARTIAL、来源定位 FAIL、外部额度 BLOCKED、夹具缺口与未运行项目。

这不是盲测、安全认证或同输入的跨模型基准。尚未验证 WPS/全部平台、实体打印、课程平台提交或所有专业知识。缺字体预检接触过判据，仅作有局限的观察。用户的真实论文始终按自己的模板、资料、当前版本和正式对象验收，不保证录用、成绩或检测分数。

## 下载、使用与回退

分发资产：`AcademicPaperEngineeringSkill_2.5.1.zip` 及其 `.zip.sha256`。解压后按[快速开始](docs/QUICKSTART.md)试用，完整复制 `skill/academic-paper-engineering-v2-5`；包内 `SHA256SUMS.txt` 可核文件身份。项目级试用不会替你覆盖全局旧版或论文原稿。回退时使用自己保留的旧目录；历史 RC Release 与版本目录独立保留。
