# 04 数据审计

## Input

冻结全文及图表、摘要、题注、附录，来源台账、原始记录、参数、公式和计算文件。

## Process

1. 扫描数字、中文数量、比例、范围、年份、倍数、排名及隐含数量断言。章节、引文、页码、标识和下标归为内部编号，说明为何不需外部来源。
2. 为每次出现登记原句和稳定位置，关联 DATA-ID；查源可以去重，但不能丢掉重复位置的不同对象或时态。
3. 沿“值 → 来源 → 发布年/数据期 → 对象 → 单位/分母 → 事实或预测 → 情景与范围”核查。阅读层级和精确页、表、段或原始数据字段记录清楚。
4. 查新增/累计、能力/产出、库存/期间量、设计/实测、样本/总体、绝对增量/增幅、百分比/百分点、部件/系统指标。相同数值不能跨口径复用。
5. 分别判断公式适用、量纲和算术、输入参数来源、结论外推范围。计算精度不能超过输入依据所能支持的精度；取整规则及必要不确定性写明。
6. 冲突先查条件和来源版本，不直接平均或改成区间。原始观测缺失、异常和处理步骤保持可追溯，不静默填补。
7. 未核项按继续查源、纠正/删除、收窄或显式假设分析处置。更改后同步所有出现位置，重扫新增数字和残留旧口径。

## Output

`DATA-ID | 出现位置/原句 | 值 | 对象 | 时期 | 单位/分母 | 性质 | 工况/范围 | SRC-ID/精确位置/阅读范围 | 状态 | 处置`。另列公式、算术、参数和外推的独立结果。

## Validation

| 数据状态 | 条件 | 允许的结论 |
| --- | --- | --- |
| Verified | 直接可读证据支持当前值、对象、时期和条件 | 仅在对应性质和范围内使用；核实预测仍是预测 |
| Partial Verified | 部分字段、阅读层级或条件尚有限 | 采用已支持部分并说明缺口 |
| Unsupported | 已查证据不支持或矛盾于当前断言 | 换对应证据重核，或纠正/删除 |
| Need Source | 没有可读依据或缺原始记录 | 查源、留待核或按允许用途设显式假设 |

作者设定、数学定义与计算基准单列来源类型；作为设定成立不等于真实世界参数有据。所有实质数字出现位置有记录；未核参数不能支持事实性结果。

## Failure prevention

待核不等于虚假，不宣称未证实的 AI 造假；精确数字不等于可信数字；不能让自己的表格证明自己的参数。只加“约”不能修正对象、单位、时期或系统边界错误。
