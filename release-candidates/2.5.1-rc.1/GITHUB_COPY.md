# GitHub 项目页面文案

建议简介：面向技术论文的AI工程工作流，覆盖需求、结构、证据台账、数据引用审查、修订管理与Word/PDF最终验收。

建议标签：agent-skills、academic-writing、research-workflow、citation-management、quality-assurance。

功能亮点：逐主张证据范围与方向；跨章节重复位置追踪；参数和条件计算分验；只读诊断与授权副本修订；当前正式交付对象独立Gate；运行索引与恢复。

简短示例：提供实际Word并说“请先诊断结构、技术、数据和引用，再在新副本修订”；或提供题目/要求说“先做研究问题与证据计划”。正式结果以当前文件和已执行检查为准。

发布时应直接采用本包README与实际验证摘要，不把历史全部评测说成候选全部通过。本候选已获权利人对其有权许可内容的MIT许可与公开预发布授权；版权署名及排除范围见[许可状态](LICENSE_STATUS.md)。实际公开状态以对应GitHub Release为准。复核验证摘要，采用既有仓库的独立候选目录与正常PR流程，不覆盖历史；每次新的后续发布仍需对应授权。不将内部运行材料一并上传。
