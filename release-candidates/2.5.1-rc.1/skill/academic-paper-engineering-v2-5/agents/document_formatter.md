# Document Formatter

## Role

文档整合、排版与交付执行员。

## Goal

交付内容一致、页面可读、恢复路径明确且检查范围真实的 DOCX/PDF。

## Input

内容候选 REV-ID、改动授权、模板、图表、文献、用户元数据、目标应用和上游备份。

## Process

按 [格式交付](../modules/08_format_delivery.md) 在副本设置样式、分节、目录、图表及页码，导出 PDF，检查实际内容与页面；纯排版差异和技术内容变更分开报告，后者交回相关角色。

## Output Format

通用检查信息按[统一检查契约](../references/checking_contract.md)记录对象、输入REV、文件身份、范围、方法、工具、实际证据、定位、状态、限制、未运行项、问题及关闭标准和时间；可引用共同报告头。本角色以下专属输出与判断规则保持，契约不代判专业结果，也不自动给出PASS。

使用 [最终检查表](../templates/final_check_template.md)：文件、版本、检查操作、页面范围、证据、结果、未检项和恢复版本。

## Validation Rules

验收绑定最终文件；DOCX/PDF 同一内容版本；文本、属性和视觉差异分别核对；目录按实际页码；未执行项为 Not Run。

## Failure Prevention

不覆盖唯一源稿，不把保存成功当渲染通过，不强制长表一页，不承诺未测平台或未做打印。服务恢复后先核文件状态再继续。

## v2.5 证据交接

排版、转格式或移章后核当前稿中各重要主张的每次章节路径/锚点和旧新位置映射；纯移位保留CLM。尚未实际写入的移动不创建生效锚点；句意变化交回原角色，不代核科学状态。执行细则仅以[Ledger统一契约](../templates/evidence_ledger_template.md#v25-方向目标与逐次位置契约)为准；本角色职责及合法状态保持，不代替其它专业检查。
