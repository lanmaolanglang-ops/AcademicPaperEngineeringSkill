# 完整使用说明

## 一 先选择本次目标

从零写作、已有稿优化、只读审查、数据或引用核查、最终文件制作都可以直接进入相应阶段。告诉Agent本次要拿到什么成果，哪些地方可以修改，哪些必须保持。无需理解内部角色或自己填写ID。

从零写作至少说明题目/方向、学科和读者、篇幅、模板、已有资料、截止时间、目标文件。没有来源时先做需求与检索计划，不要求它凭空写出实证结论。已有Word时应先实际读稿，诊断结构/技术/数据/引用，再在授权范围内改副本。只读请求不允许顺手改正文。

## 二 材料怎么提供

提供实际文件或完整文本。链接不保证附件可取，文件名不保证内容已读。Agent应区分已读全文、部分片段、元数据、历史报告和不可访问材料；不可读为[NOT_AVAILABLE]。扫描PDF和复杂表格可能需要OCR或页面查看，不能只用文字提取冒充全页检查。

提交模板、原始实验/问卷/测量记录必须由真实资料提供。需要个人信息的封面只用于你的项目，不写回可公开Skill或案例。不要发送与任务无关的凭据。

## 三 规划与写作会得到什么

需求契约说明目标/硬要求/验收方式。提纲说明每章回答的问题、前提、证据需求和后续关系。技术章节围绕问题、原理、现状、优势、限制和适用边界展开，实验/调研按真实方法与记录调整，不套原案例固定章数。

写作按实际材料和证据推进。事实、预测、假设、计算、推论和建议有不同性质；模型结果不是实测，假设不是现实参数。摘要和结论需回指主体，不新增未论证数据。

## 四 如何读懂证据台账

主张CLM是“说了什么”；位置是它在当前REV中出现在哪里；SRC是来源身份；EVID是实际读到的证据片段；DATA管理数字/参数。来源可以支持一条主张，不代表支持所有相关主张。正文显示引用号不是来源唯一ID。

每条关系应写清它核对的是完整结果、一个输入还是某个前提。支持、反驳、背景相关和未建立支持分别判断。反例不能写成对原普遍断言的部分支持；不能由材料不支持就断言作者造假。

| 关系或数据状态 | 含义 |
| --- | --- |
| Verified | 仅在声明对象/时期/条件和性质内有依据 |
| Partial Verified | 部分内容已核，必要范围或环节仍缺 |
| Unsupported | 所查依据不能支持当前目标或与其冲突，不自动等于造假 |
| Need Source | 需要的来源/原始记录尚缺或不可读 |
| Unknown | Ledger尚未判断或变更后待重判；不是低风险默认值 |

Unknown只用于Ledger，不加入数据审计的四状态。算术、参数和外推独立：条件算式可以正确，但现实参数仍Need Source。完整推论可以由多条前提和实际推导组成，单个输入来源不能被标成直接证明完整结论。

## 五 修改如何同步

同一主张在摘要、正文、表格、图注和结论中复用时，每次都应记录当前章节与锚点；同段重复也要区分。改一个年份、对象、数值或限定后，检查所有相关位置、引文和图表，而不是全文机械替换数字。

REV标识稿件版本，DEC记录决定和实际写入，ISSUE记录问题和关闭依据。提议移动不是已经移段，旧报告不能只改REV标签继续使用。需要恢复时要求Agent先指出当前文件、已完成检查和下一步，避免从头重做或覆盖底稿。

## 六 Word和PDF如何验收

先保留原稿，在新副本设置样式、图表、参考文献、目录和页码。PDF应来自同一内容版本，实际检查页面、目录目标与页码、图表分页、清晰度、裁切和异常空白。导出日志和文本提取不能替代版面检查。

正式对象由你的需求决定。只要Markdown报告时不凭空追加Word要求；如果要求Word/PDF，缺一个文件或缺必要页面检查就不能因前面的文字通过而放行。没有Office工具不能假称已导出；先交可复核阶段成果和阻断项。

## 七 最终判定怎么用

请求“能否提交”时，即使材料不齐也应实际给出正式Gate判定，而不是只说Markdown阶段PASS。PASS仅在规定条件均有当前有效证据时成立；PARTIAL仅用于所有阻断项已满足后的明确低风险非硬要求残留；关键缺口或必检未运行是BLOCKED；未请求/未开始是NOT RUN。

上游报告必须绑定当前对象和范围。教师完整要求未知、引用支持缺口、关键参数无实证、严重问题未关闭、实际交付对象未核，不能靠引用数量或文件生成成功消除。评测通过与真实论文提交判定是两回事。

## 八 减少不必要的往返

一次说明用途、修改授权、资料和硬要求；资料足够时让Agent继续已授权工作。小任务允许一个报告包含台账、位置、问题和结果，不要求几十个文件。只有改变研究目标、超出修改范围、必须提供原始记录或存在真实权限限制时才需要你决定。

## 九 范围与责任

流程改善可追溯性，不是外部专家认证，不保证录用、成绩、检测率或所有平台。关键专业判断和正式提交仍需要人工复核。没有运行的实验、打印、平台提交、跨模型验证不能写成完成。
