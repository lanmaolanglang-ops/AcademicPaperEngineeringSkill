# Academic Paper Engineering Skill v2.1 升级说明

本次在独立 `AcademicPaperEngineeringSkill_v2.1` 目录增强 v2.0，未安装到全局目录。旧版目录和 ZIP 保留，新包完整复制其 27 个文件，再仅在新版入口上更新版本及增加路由。

## 1. v2.0 保留内容

九个模块、五个原角色、三个原模板、三个知识库均保留，文件路径和字节不变；原九阶段、十一条运行原则、数据四状态及问题/修改管理规则继续有效。

原六份报告逐文件保留，作为 v2.0 的历史记录。它们的旧版本号、目录树和旧版检查数仍描述当时交付；本版当前范围以此升级说明和 [v2.1验收报告](v2.1验收报告.md) 为准。

## 2. 新增内容与原因

| 能力 | 新文件 | 解决的问题 |
| --- | --- | --- |
| Evidence Ledger | [evidence_ledger_template.md](skill/academic-paper-engineering-v2/templates/evidence_ledger_template.md) | 逐主张说明具体证据、支持范围、数字口径和推导链，避免一个来源自动背书全部相关句子 |
| Final Acceptance Controller | [final_acceptance.md](skill/academic-paper-engineering-v2/agents/final_acceptance.md) | 只读判断当前成果是否满足交付契约，避免把结构、格式或旧版通过视为整篇完成 |
| Final Acceptance Report | [final_acceptance_report.md](skill/academic-paper-engineering-v2/templates/final_acceptance_report.md) | 将对象、版本、范围、方法、证据及残留事项绑定到唯一最终结论 |
| User Prompt Templates | [user_prompt_templates.md](skill/academic-paper-engineering-v2/templates/user_prompt_templates.md) | 给普通用户提供从零写作、深度优化、提交审查及Word/PDF四种入口 |

Evidence Ledger 与控制器规则直接存于上述模板和角色文件，不另增主流程模块、数据库、服务或执行脚本。

## 4. 对原流程的影响

| 接入点 | 新增动作 | 原职责保持 |
| --- | --- | --- |
| 写作与资料整理 | 主 Agent 建立或复用主张—证据关系，增加具体 EVID-ID | 原CLM/SRC/DATA/CIT/REV继续使用 |
| 数据审计 | 台账关联每个DATA-ID与数字出现位置，读取原审计结果 | data_auditor仍负责数字、参数和计算 |
| 引用与技术审查 | 台账保存来源支持部分、前提和推导链 | citation_checker核来源和匹配；academic_reviewer核技术与推论 |
| 排版与修改 | 更新位置锚点及受影响主张，记录范围未变的证据 | document_formatter管文档；revision_management管版本和复核 |
| 最终交付 | 控制器读取当前有效报告，输出三选一结论 | 控制器不写稿、不补源、不替原角色审查 |

低风险且非硬要求的残留可得到 CONDITIONAL PASS，但不被自动关闭；关键未核事实、未知风险、重大问题或缺少必需文件得到 BLOCKED。合法的显式假设分析按任务契约判断，不把其参数升级为已核实事实。

## 5. 兼容性说明

- 数据审计仍只有 Verified、Partial Verified、Unsupported、Need Source 四状态。Ledger 的 Unknown 只用于尚未判断的主张关系，不输入旧数据状态字段。
- 逐项检查沿用 Passed/Failed/Not Run/Not Applicable；最终结论独立为 PASS、CONDITIONAL PASS、BLOCKED。
- 一个主张对应多个证据行；一个来源多次使用逐项判支持。既有台账已含所需字段时引用即可，不强制重复抄写。
- 旧报告仅在对应范围未变或差异复核已有证据时显式沿用；不能只把其REV-ID换成新版。
- 包内 `skill/academic-paper-engineering-v2/` 路径不变，以保留旧相对链接。新版入口识别名为 `academic-paper-engineering-v2-1`；v2.0 的原名仍在原包中。未自动注册别名、安装或改变任何全局配置。
- 需要安装时分别使用独立存放目录，遵循目标工具的发现机制；包的文件并存已经实现，不声称验证了某个工具的同时加载行为。
