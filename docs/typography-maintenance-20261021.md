# 中文论文排版维护候选 2026-10-21

版本身份：2.5.1-rc.1+typography.20261021。它是可下载的维护候选源码与分发快照，**不是新的GitHub Release或稳定2.5.1**。原v2.5.1-rc.1标签、Release、分发资产及历史目录保持不变。快照内“本地候选、未发布”描述构建时状态，不代表已有新Release；是否安装由使用者自行决定。

## 这次改善

- 无模板中文课程论文采用明确可覆盖的产品默认：正文宋体小四，西文Times New Roman，标题黑体，黑色；对齐、缩进、行距、段距和不同角色分别指定。学校/期刊/用户模板优先，默认值不是所有学校统一标准。
- 排版检查核实际有效字体、字号与段落参数，清理与所选样式冲突的主题字体/颜色/边框。代码写入字体名、保存文件或PDF可读均不能替代检查。
- 增加一个可选辅助脚本，仅按输入哈希及显式段落角色映射处理无模板普通文字，只写新副本，不猜角色、不自行安装依赖、不宣布论文通过。
- 同时保留前一维护候选对提交硬要求、未关闭低风险问题、逐页覆盖、工具副作用边界及证据关系输出的补强。这些不是新的核心模块。

九模块、六角色、七模板、三顶层知识文件和原案例保留；不增加Agent或数据库，Evidence Ledger、ISSUE/DEC/REV及正式提交Gate职责不变。

## 已实际验证的范围

本次排版维护：16项静态检查、163条相对链接/锚点；55个映射段落、825项本机原生Word有效属性核对；旧主题冲突样例、11角色默认样张及提供模板的实际DOCX；Word与LibreOffice导出最终共13个后端页面均实际查看，并核文字覆盖和字体。输入哈希错误、覆盖目标、无效位置及user-template误用默认脚本的拒绝分支已实际运行。分发ZIP实际重开，CRC、成员路径、55成员逐文件SHA及解压回查一致。

标题在当前Word从MS Gothic纠正为黑体；默认正文为宋体12pt，西文为Times New Roman。用户模板中的仿宋11pt、楷体20pt和30mm左右边距保留。测试样张不是完整或可正式提交的真实论文。

前一候选的四次普通豆包定向运行：缺少要求的结果图时实际BLOCKED、未关闭低风险问题时实际PARTIAL、全部页面实际查看的三个目标满足；证据契约仍PARTIAL。它们是前一候选的实际记录，不能自动视为本快照的新测试成绩。

- 本次排版补丁未执行新的豆包/独立模型行为回归；不能保证Agent自动正确判断段落角色。脚本的角色映射错误须在当前对象上复核。

- 首轮核验器曾错误解释Word行距及表格索引，已修正方法后复核；初轮失败与产物均在维护者私人证据中保留。官方渲染器退出0且产物有效，stderr仍有子进程读流编码错误，不宣称工具日志完全无缺口。
